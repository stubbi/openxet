Built in the open

Good storage should fit your world.

openxet brings the Xet protocol to infrastructure you control, platforms you build, and a hosted service you can choose.

One project, three ways to use it

The goal is simple: store large files and reuse the parts already stored. Run openxet yourself, embed it behind your own product, or use hosted openxet when it launches. The hosted service will run the same released open-source build.

Today, the storage-only server and client are available from source. The Hub and Git layers and hosted service are planned. The documentation explains what works now.

Independent, with shared foundations

openxet implements the Xet protocol developed by Hugging Face. It is an independent project, not affiliated with or endorsed by Hugging Face. The code is available under the Apache 2.0 license.

People behind the code

The project is maintained by Jannes Stubbemann. Decisions, implementation work and contributions are tracked in the public repository. We want feedback from people running storage, building platforms and trying to move their first large file.
