Open-source Xet storage server

Upload only what changed. Keep it where you choose.

openxet is an open-source server for Xet, the storage protocol Hugging Face built for large files. Hugging Face’s own hf_xet client works with it unmodified and sends only the chunks your server doesn’t have yet.

Why the second upload is small.

A new version of a large file often repeats most of the old one. Xet finds those repeated parts and gives them a second use. The file you work with stays whole.

  1. 1

    Split by content

    The client cuts your file into chunks of about 64 KiB at boundaries set by the content itself, so an edit only moves the chunks around it.

  2. 2

    Ask what’s stored

    It asks your server which chunks it already has, from any earlier file, not just the last version.

  3. 3

    Send the rest

    Only new chunks travel. A download puts the chunks back together into your complete file.

This is deduplication, as specified by Hugging Face’s Xet protocol. Savings depend on how much your versions share. Read the Xet specification ↗

Before you decide.

Looking for a technical detail?
Start with the documentation.

Is openxet part of Hugging Face?

No. openxet is an independent open-source project that implements the Xet protocol published by Hugging Face. It is not affiliated with or endorsed by Hugging Face.

Can I use hf upload or Git with it today?

Not yet. Today hf_xet and the openxet command line upload and download directly against the storage server. The Hub API, hf upload, huggingface_hub, Git and LFS are the next milestone, in development now. Follow the changelog.

How much will I save?

That depends on how much your versions share. In our measurements an appended log’s second version reused about 90% of its bytes, while two consecutive dense training checkpoints reused almost nothing, because every weight changes. Compressed and encrypted files deduplicate poorly. Read the measurements.

Is it only for AI models?

No. openxet stores any large file. Models and datasets are common examples; logs, uncompressed archives and other versioned files fit too.

What if I want to leave?

Self-hosted, your files sit in the standard Xet format in a directory you own, and the code is Apache 2.0, so you can keep running it without us. Export terms for hosted openxet will be published before launch.

What will the hosted service cost?

Pricing, limits and hosting locations will be published before launch. Join the waitlist for one email when hosted openxet is ready to try. Joining does not create an account or require payment.
