# Security policy

## Reporting a vulnerability

Please report privately, not in a public issue or PR.

Use GitHub's private vulnerability reporting:
<https://github.com/stubbi/openxet/security/advisories/new>

Include affected version or commit, impact, and steps to reproduce. Only the
maintainers can see the report.

There is no security mailbox yet; this page will list one when it exists.

## What to expect

- Acknowledgement within **2 business days**.
- A fix or a written plan with a date within **14 days**.
- Coordinated disclosure: we publish a GitHub Security Advisory with credit
  to the reporter (if you want it) when a fix is available.

## Supported versions

| Version | Supported |
|---|---|
| pre-1.0 | latest `main` only |

## Scope

Anything in this repository, including the server, the client and the
release pipeline. Protocol-level issues in the Xet specification or
`xet-core` itself should go to [Hugging Face](https://github.com/huggingface/xet-core/security);
tell us too if openxet is affected.
